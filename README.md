## 👨‍💻 Sobre mí

Soy **Full Stack Developer** y estudiante de **Ingeniería en Informática en la Facultad Politécnica de la Universidad Nacional de Asunción (FPUNA)**.

Actualmente cuento con experiencia profesional en el desarrollo y mantenimiento de soluciones empresariales, trabajando principalmente con **Python, Odoo, PostgreSQL y APIs REST**.

Mi trabajo se enfoca en la implementación de lógica de negocio, desarrollo de módulos personalizados, automatización de procesos, integración entre sistemas y resolución de problemas en aplicaciones existentes.

También desarrollo soluciones web utilizando tecnologías como **Django, FastAPI, JavaScript, HTML, CSS y Tailwind CSS**, complementando el backend con interfaces funcionales cuando el proyecto lo requiere.

Me interesa especialmente continuar creciendo en áreas como **backend development, diseño de APIs, arquitectura de software, integración de sistemas y desarrollo de aplicaciones empresariales**.
